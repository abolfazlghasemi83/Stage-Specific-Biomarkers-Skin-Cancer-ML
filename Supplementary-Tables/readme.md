<div align="center">

### [Supplementary Table S1.xlsx](./Supplementary%20Table%20S1.xlsx)

</div>

Comprehensive functional enrichment analysis of the stage-associated biomarkers.

The workbook includes results from seven annotation resources:

|        Database        | Annotation Type                  |
| :--------------------: | :------------------------------- |
| **Gene Ontology (GO)** | Biological Process               |
|        **KEGG**        | Pathway analysis                 |
|      **Reactome**      | Pathway analysis                 |
|    **WikiPathways**    | Pathway analysis                 |
|      **DisGeNET**      | Disease and gene associations    |
|       **HuBMAP**       | Tissue and cell-type annotations |
|      **DrugAtlas**     | Drug-gene associations           |

The workbook contains enrichment terms, associated genes, and statistical results used to support the biological interpretation presented in the manuscript.

The complete enrichment analysis is referenced throughout the manuscript and provides the detailed results underlying the summarized pathway-level findings.

<div align="center">

### [Models-Output.xlsx](./Models-Output.xlsx)

</div>

Consolidated outputs from the comparative machine learning and statistical analysis.

The file contains structured results for the analyzed disease-stage and sub-stage comparisons, including:

|           Output           | Description                                                 |
| :------------------------: | :---------------------------------------------------------- |
|        **Accuracy**        | Classification performance across stage transitions         |
|        **Precision**       | Precision results for the evaluated methods                 |
|   **Feature Importance**   | Feature-level importance and ranking results                |
| **Stage-Specific Results** | Model outputs for individual stage comparisons              |
|   **Biomarker Rankings**   | Candidate genes identified through feature-ranking analysis |
|   **Cross-Model Results**  | Comparative outputs across analytical methods               |

This workbook provides the detailed model-level outputs supporting the performance analysis and biomarker prioritization reported in the manuscript.
